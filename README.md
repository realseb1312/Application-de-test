# Application de test

Petite application web de test créée avec Vibe.

## Contenu
- `index.html` — page d'accueil
- `style.css` — styles
- `script.js` — logique de test (compteur de clics)

## Utilisation
Ouvrez simplement `index.html` dans un navigateur, ou consultez le site via GitHub Pages (Settings → Pages → branche `main`).
